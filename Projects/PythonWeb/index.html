¿Cómo funciona esto?

Esta página carga Pyodide, una build de CPython (el intérprete normal de Python) compilada a WebAssembly, y con eso arma una consola interactiva tipo REPL directamente en el navegador. No hay ningún servidor ejecutando tu código: todo el intérprete de Python corre dentro de esta misma pestaña.

Cómo usarla

  • Escribe cualquier expresión o instrucción y presiona Enter.
  • Las expresiones muestran su resultado automáticamente, igual que en el REPL real de Python; usa print() si quieres forzar una salida.
  • Usa las flechas ↑ / ↓ para navegar el historial de comandos.
  • Puedes definir funciones, usar import con la librería estándar, manejar excepciones, etc. — es Python de verdad, no una simulación.
  • Si llamas a input(), Pyodide abre el cuadro de diálogo nativo window.prompt() del navegador para pedirte el valor (es el comportamiento por defecto de Pyodide, no algo que arma esta página).

Estructura de archivos

tu-proyecto/
├── index.html
├── style.css
├── console.js
└── pyodide/    <- runtime de Pyodide (WASM + stdlib de Python)

Lo que hace console.js

  1. Carga Pyodide con loadPyodide().
  2. Redirige stdout/stderr de Python hacia la consola con pyodide.setStdout() / setStderr().
  3. Por cada línea que escribes, la corre con pyodide.runPythonAsync(codigo) y muestra el resultado si la expresión devolvió algo.
